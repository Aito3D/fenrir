    What changes, in every proposition
    • One search, many fields: code, title, description, tags, client, order number, item and file names, printer, material. Matches are highlighted; / focuses the box.
    • Important facts on the card: thumbnail, code, title, who it is for (client + open order), what is ready (files · recommended revision), what it prints on (printer · nozzle · material), printed count and last activity. No more "Active · Prints: 0" filler.
    • Quick filters instead of the status dropdown alone: In production, Ready to print, No file yet, material.
    • Printing files one step away: A opens a drawer, B shows them beside the list, C unfolds them in the row. Print, preview and download act from there; "Open project" goes to the full page.
    • Folders (B): a tree of folders (any depth, e.g. Car › Wheel cap) holds projects; a project sits in one folder or in none. New folder from the list header; move a project by dragging it onto a folder or with its button. A search flattens the tree and shows each hit's folder path; folder names are searchable too.
    • Sort by last activity by default, so the catalog reads like the shop's week, not like an ID sequence.
